# Desktop Organizer

A macOS desktop workspace organizer built with SwiftUI and AI-assisted development.

## Project Background

Mac desktops can easily become cluttered when working on multiple projects. Project documents, screenshots, images, PDFs, and temporary files are often mixed together.

Desktop Organizer explores a spatial approach to file organization by allowing users to organize files into visual Zones.

## Core Problems

1. Files from different projects are mixed together.
2. Screenshots and saved images accumulate quickly.
3. Traditional folders do not visually represent the user's current working context.

## Product Concept

Desktop Organizer organizes files through visual Zones.

Initial Zone types:

* Project Zone
* Screenshot Zone
* Inbox Zone

## MVP

The first version will support:

* Create a Zone
* Rename a Zone
* Delete a Zone
* Drag files into a Zone
* Display files inside a Zone
* Open the original file
* Save Zones between app launches

## Tech Stack

* macOS
* Swift
* SwiftUI
* Git / GitHub
* AI-assisted development

## Current Stage

Product definition and prototype design.

This project is both a real productivity tool and an experiment in AI-assisted product development.

The development process will document product decisions, prompts, AI-generated code, debugging, testing, iteration, and reflection.
